# Release Notes

## v1.0.0 - 2026-08-02

Initial public release of FitnessApp.

### Included

- Spring Boot backend for workout planning, logging, and analytics.
- JWT-based authentication and protected API routes.
- Exercise, plan, workout, and set management endpoints.
- Deterministic calculators for 1RM, strength ratios, and set predictions.
- Strength timeline, stimulus analysis, and recommended weight services.
- React + TypeScript frontend scaffold with auth, dashboard, plans, generator, logger, and analytics pages.
- Windows desktop launch scripts and installer assets.

### Validation Snapshot

- Repository pushed to GitHub.
- Root documentation added with setup and run instructions.
